= T

A more convenient wrapper for Vim's frequently used `:term_sendkeys` terminal function.

.vim
[source,vim]
----
" assuming `16` is indeed a terminal buffer
:let term_buffer_id = 16
:'<,'>y | call term_sendkeys(term_buffer_id,@")
----

[NOTE]
====
Everytime you are specifing new terminal buffer id to work with it's remembered.
In subsequent calls, you can omit the terminal buffer id.
====

.vim with T plugin shortcuts
[source,vim]
----
" t - terminal, write command in terminal mode
:Tt 16 ls -la
" Send <CR> (Enter) to the terminal. As a side effect, `16` is
" remembered as the terminal buffer we are working with right now.
:Tt 16
" Now we can omit `16`. The following command is the same as
" the previous one.
:Tt

" m - multiple, <CR> after each visually selected line
:'<,'>Tm 16
" When the buffer ID is omitted, the previous one is used.
:'<,'>Tm

" s - single, join all lines into one
:'<,'>Ts 16
----

.you can also create remappings
[source,vim]
----
nnoremap <leader>tt :Tt<CR>
vnoremap <leader>ts :<C-u>Ts<CR>
vnoremap <leader>tm :<C-u>Tm<CR>
----
